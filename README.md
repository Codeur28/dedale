# Dédale des Jardins

Jeu de labyrinthe dans le navigateur : 70 niveaux en 7 chapitres (clés, brume, chrono, veilleurs, portails, boue, haies mouvantes, miroirs, lucioles), en solo ou jusqu'à 4 joueurs sur le même clavier.

Tout tient dans `index.html`, sans installation. Jouer en ligne : https://codeur28.github.io/dedale/
